# Vidéos du site

Déposez ici vos fichiers vidéo. Ils sont copiés dans `dist/media/` à chaque
génération et servis sous `/media/`.

| Usage | Format conseillé | Exemple de chemin |
| --- | --- | --- |
| Bande verticale (15 emplacements) | MP4 H.264, 9:16, 6 à 12 s, moins de 3 Mo | `/media/rituel-01.mp4` |
| Grande vidéo paysage | MP4 H.264, 16:9, 1080p | `/media/film-417.mp4` |

Dans le back-office, rubrique **Contenu du site** :

- **Vidéos verticales** : renseignez le chemin dans « Fichier vidéo » et une
  image dans « Affiche ». Sans fichier, l'affiche seule est montrée.
- **Grande vidéo paysage** : même principe, le lecteur affiche les contrôles.

Les vidéos verticales sont muettes, bouclées, et ne se lancent que lorsqu'elles
entrent dans l'écran.
